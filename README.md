LAKbayGAbayPh is an interactive travel tracking system designed for explorers navigating the 82 provinces of the Philippines. It serves as a personal "Mapasayo Generator," allowing users to visualize their journey, document their stays, and plan future adventures with ease.

✨ Features
Interactive Province Map: A dynamic map interface (powered by Leaflet.js) to track visits across all 82 provinces.
Real-time Statistics: Instant tracking of provinces visited vs. stayed, including percentage completion and region-based breakdowns.
Travel Center: A dedicated hub for viewing upcoming long weekends and managing travel notes with countdown timers.
Secure Access: Simple "Explorer Alias" and 6-digit PIN login system for personalized tracking, or guest access for quick use.
Progress Visualization: A sleek dashboard showing island group progress (Luzon, Visayas, Mindanao)
